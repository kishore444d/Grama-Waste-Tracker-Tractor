# Grama Waste Tracker - Tractor App

Realtime GPS Location Sender Application for Smart Rural Waste Monitoring System.

## Features
- Live GPS Tracking
- Firebase Realtime Upload
- Continuous Location Updates
- Cloud Synchronization

## Technologies Used
- Kotlin
- Android Studio
- Firebase Realtime Database
- GPS Location Services

## Workflow
GPS → Firebase → Admin App

## Project Description
The Tractor App continuously captures and uploads live vehicle GPS coordinates to Firebase Realtime Database for realtime monitoring.
